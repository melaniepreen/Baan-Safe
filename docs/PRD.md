## 1. Product

BaanSafe is a flood call-triage scaffold for a synthetic Thai flood. A call is triaged, a provisional dispatch can be named, and aid casework is a separate check that does not approve a payment. Mubit is the LLM gateway and the trace record. It records every System 2 call, groups calls that share a model, system prompt, tools, and output format into one task, and trains a per-task adapter. It does not reason and it exposes no memory API. Memory is BaanSafe's own store behind `memory/adapter.py`. `llm.client.complete` sends `x-middleware-record: full` on every call (`37e5ab1`; this reverses the #23 never-send rule for that client). Never send `x-middleware-store: false` or `x-middleware-record: metadata` or `off`. `llm/openai_client.py` does not add the record header. The field precheck picks one entry point; `config/routing.yaml` `mode: cascade` lets a System 1 escalate continue to System 2 in the same turn (the no-stub fallback outcome never cascades). Every LLM call goes through `llm/client.py` or `llm/openai_client.py`. Both refuse a host that is not `api.mubit.ai` or a `mubit.ai` subdomain. `llm.provider_route` is `mubit`. The OpenAI SDK base is the Mubit compat prefix (`/compat/openrouter/v1`). There is no OpenRouter client.
