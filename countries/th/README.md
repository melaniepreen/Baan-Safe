# Thailand

`pack.yaml` describes the code on `main`. It is the default and the demo. `runtime: unloaded` means the gateway, the extractor, ingest, and the town do not read it.

Live quotations stay in `policies/`, including `policies/triage.yaml`, `policies/flood.yaml`, and `policies/mof_relief.yaml`. This directory does not copy them.

`countries/THAILAND_ASSUMPTIONS.md` is the line inventory.
