# Philippines

Worked example of a second flood-prone country. It is not loaded, and it is not the demo. `default_demo` is false.

911 is the only short code stored, from the Emergency 911 National Office page cited in `pack.yaml`. Trunk lines were not copied. National triage colours and assistance amounts are empty. OSM `admin_level` is recorded only where a source named it, and it is not Thailand's query.

`policy-pack.yaml` and `system1_labels.yaml` follow `countries/TEMPLATE/`. Filipino hypotheses are drafts. `quotation` is false, and a speaker has not signed them.
