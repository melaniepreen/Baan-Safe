# RL loop snapshots

`eval/out/` is gitignored, so `make rl-loop` output lives only on the machine that ran it. This folder keeps committed copies. One folder per run, named `<UTC stamp>-<memory mode>`.

| Snapshot | What | Headline |
|---|---|---|
| `20261025T0407Z-memory-empty` | 3 epochs x 48 episodes, live Nemotron via Mubit, `.env` had the dormant `MEMORY_IMPL=mubit` so every prompt carried `memory: []` (HANDOVER audit A1/A2). `overlay.json` is the run's `final_overlay`: 1 graduated rule (`RL-ROAD-3`, no needs → P4 information_only), 1 demoted | 20/48 correct, 9 critical under-triage, flat reward; 54 live calls, 154 cache hits |
| `20261025T0600Z-memory-local` | Same loop with `MEMORY_IMPL=local` on a store seeded with the 10 policy lessons (grew to 217 rows during the run). Includes `training/` fine-tune exports (s1 18, s2 36, prefs 8) | 22/18/21 correct, 2/3/2 critical under-triage, reward −0.125 → 0.189; ~133 live calls, 84 cache hits, 0 graduated, 2 recommendations, 1 demoted |

Files per snapshot: `run.json` (what `GET /rl/run` and `GET /training` read), `overlay.json` (`RL_OVERLAY` input), `rl.md`, `s2_cache.jsonl` (exact-key Nemotron replies; `make rl-loop-replay` input), optional `training/`. `traces.jsonl` is not kept (2 MB, regenerated by any run).

## Commands

```
make rl-snapshot                       # copy eval/out/rl → eval/snapshots/rl/<stamp>-<MEMORY_IMPL>
make rl-restore SNAPSHOT=20261025T0600Z-memory-local   # copy back so rl-loop-replay / /rl/run work on a fresh clone
make rl-loop-replay                    # cache only, no network
make rl-compare A=20261025T0407Z-memory-empty B=20261025T0600Z-memory-local   # side by side → eval/out/rl_compare.md (+ .json); no args = first vs last
```

`GET /training/compare?a=<folder>&b=<folder>` returns the same comparison; `/ui/training.html` draws it as the "Memory off vs on" card.

Hosted: `modal volume put --force baansafe-demo eval/snapshots/rl/<stamp>/run.json rl_run.json` puts a snapshot on `/training`.

Everything here is synthetic: fixture callers, invented names, Sukhumvit/Watthana sois. `make validate` scans it.
